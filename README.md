A program that draws Saturday 21 November 2026's world news as a newspaper front page: Russia's overnight barrage on Ukraine with missiles landing in Poland, the Wall Street rout (S&P 500 -3.7%, Nasdaq -5.3%), COP31 climate talks in Antalya running into overtime with fossil fuels dropped from the draft, and the UK-EU post-Brexit reset signed in Brussels. Pure Python 3.13 standard library — a hand-drawn 5x7 bitmap font and a zlib PNG writer — no network, fully deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
